# Third-Party Assets and Image Licensing

## Repository policy

The public repository intentionally does **not** redistribute third-party
photographs whose licensing terms have not been verified for repository use.

The source code is separate from example photographs: an open-source license
applied to the code does not grant rights to third-party images.

## Seasonal color reference

The 12-season framework used by this project is informed by the established
personal-color-analysis terminology. One external visual reference consulted
during development is The Aligned Lover's *Explore the 12 Color Seasons* page:

https://thealignedlover.com/explore-the-12-color-seasons/

That page is referenced for conceptual/visual context only. Its photographs
are **not redistributed by this repository**.

The Aligned Lover's terms state that its content, including images, is
protected intellectual property unless otherwise stated and restrict copying,
reproduction, and redistribution. Therefore, no such images are included in
this repository without separate permission.

## Adding images later

If you want to add example photographs, use one of the following:

1. photographs you created or otherwise own;
2. images with a license that explicitly permits the intended redistribution;
3. images for which you have written permission covering repository
   redistribution.

For every third-party asset that is added later, record the source, creator,
license/permission, and any required attribution in this file.
