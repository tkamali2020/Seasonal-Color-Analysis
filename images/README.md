# Input images

This directory is intentionally distributed without sample photographs.

To run the end-to-end pipeline, place images here that you own or that are
licensed for processing and redistribution under the terms applicable to your
use case.

Supported extensions:

- `.jpg`
- `.jpeg`
- `.png`
- `.bmp`
- `.webp`
- `.avif`

Do not add photographs downloaded from third-party websites unless their
license or written permission explicitly allows redistribution in this
repository.
